TNDA Week 02 課前預習｜雙角色入場與格鬥攝影機

課前先完成環境確認與兩組實作，帶著紀錄進入課堂。

本週目標課前準備課前實作 1｜畫出雙角色與攝影機的關係（30 分鐘內）課前實作 2｜調整雙人構圖範圍（30 分鐘內）教材專案內要使用的文件官方參考資料上課前確認

本週目標

看懂 stage1 如何建立 1P、CPU 與共用格鬥攝影機，並從既有攝影機設定觀察雙方距離和畫面遠近的關係。

課前準備

  • 使用本週提供的 TndaFighter 教材專案。
  • 確認專案能編譯並開啟 /Game/Fighting/stage1。
  • 確認 PIE 後畫面中同時出現 1P、CPU 與雙人構圖。
  • 操作前先確認 GitHub Desktop 沒有自己尚未整理的變更。

課前實作 1｜畫出雙角色與攝影機的關係（30 分鐘內）

給學生看的題目

比較 stage1 在編輯狀態與 PIE 執行期間出現的物件，找出 PlayerController、1P、CPU Spawner、CPU 與 FightingCameraActor。畫一張架構圖，標示哪些物件原本就在關卡中、哪些在執行時產生，以及彼此的生成、控制與 View Target 關係。

要帶來上課的紀錄

  • 一張編輯狀態的 World Outliner 畫面。
  • 一張 PIE 執行期間的 World Outliner 畫面。
  • 一張包含五個指定角色及其關係的架構圖。
  • 一段不超過 100 字的說明：PlayerController 控制的對象和畫面觀看的對象是否一定相同？

課前實作 2｜調整雙人構圖範圍（30 分鐘內）

給學生看的題目

閱讀教材專案內的 FightingCameraActor 架構流程文件，找出會影響「1P 與 CPU 最遠能離多遠」及「兩人靠近時鏡頭能拉多近」的設定。各做一次調整並在 PIE 比較結果，記錄修改前後的數值與畫面；測試結束後恢復教材原始設定。

要帶來上課的紀錄

  • 你找到的設定名稱，以及各自影響的畫面結果。
  • 修改前、修改後的數值對照。
  • 最遠距離與近距離構圖各一組前後對照畫面。
  • 一句話說明為什麼角色距離上限與鏡頭距離上限不是同一件事。

教材專案內要使用的文件

  • 教材專案 docs/ 內的 FightingCameraActor 架構流程文件。
  • 教材專案 docs/blueprints/ABP_Manny_Combat.md。
  • 教材專案 docs/blueprints/changes/2026-09-01-blocked-movement-locomotion.md。

官方參考資料

  • Epic Games：Gameplay Framework Quick Reference：說明 Actor 可預先放入 Level 或在執行時生成，以及 Controller、Pawn、Possession 與攝影機的基本責任。
  • Epic Games：Cameras in Unreal Engine：說明 CameraActor、PlayerCameraManager 與 ViewTarget 的關係。
  • Epic Games：Graphing in Animation Blueprints：說明 EventGraph 更新動畫資料、AnimGraph 輸出 Pose 的分工。
  • Epic Games：Enhanced Input：介紹 Input Action、Input Mapping Context、Modifier、Trigger 與執行時 Context 管理。

上課前確認

  • stage1 能正常進入 PIE。
  • 已辨認編輯狀態與執行時才出現的物件。
  • 雙角色與攝影機架構圖已完成。
  • 攝影機設定的前後數值與畫面已記錄。
  • 測試後已恢復教材原始設定。
