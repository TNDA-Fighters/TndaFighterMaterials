TNDA Week 01 課前預習｜開發環境與 Third Person 專案

課前先完成環境確認與兩組實作，帶著紀錄進入課堂。

本頁導覽

本週目標 課前準備 課前實作 1｜比較四種 Third Person 玩法 課前實作 2｜讓專案從 Combat 關卡開始 官方參考資料 上課前確認

本週目標

先確認開發環境可以正常使用，再從同一份 Third Person 教材專案比較四種玩法起點，最後把 Combat 關卡設成專案的啟動內容。

課前準備

開始兩組實作前，先完成以下準備：

  • 安裝 Unreal Engine 5.8。
  • 安裝 Visual Studio 2026，並備妥 Unreal C++ 開發所需元件。
  • 安裝 GitHub Desktop，確認能開啟教材版本庫並查看檔案變更。
  • 取得並開啟 ThirdPersonTemplate 教材專案，確認專案可編譯且能進入 PIE。

後續課堂會使用 Codex，示範 AI Agent 如何透過 MCP 操作 UE 資產。

課前實作 1｜比較四種 Third Person 玩法

使用 PIE 依序體驗 Lvl_ThirdPerson、Lvl_Combat、Lvl_Platforming 與 Lvl_SideScrolling。整理四種玩法在角色操作、鏡頭、關卡互動與遊戲目標上的差異，並為每個關卡留下一張能看出特色的執行畫面。

預習成果紀錄

  • 一張四種玩法的比較表。
  • 四張 PIE 畫面，每個關卡各一張。
  • 一句話說明你會選哪一種玩法當作近戰遊戲的起點，以及理由。

課前實作 2｜讓專案從 Combat 關卡開始

把編輯器啟動時開啟的關卡，以及遊戲使用的預設關卡，都改成 Lvl_Combat。關閉並重新開啟專案，確認編輯器會直接進入 Combat 關卡，而且 PIE 可以正常操作角色。

預習成果紀錄

  • 一張顯示兩項預設關卡都已改成 Lvl_Combat 的設定畫面。
  • 一張重新開啟專案後的編輯器畫面。
  • 一張 Combat 關卡的 PIE 畫面。

官方參考資料

  • Epic Games：Third Person Template：介紹標準 Third Person 範本，以及 Combat、Platforming、Side Scroller 三種 Variant。
  • Epic Games：Changing the Default Level：說明 Game Default Map 與 Editor Startup Map 的設定位置。
  • Microsoft Learn：Install Visual Studio Tools for Unreal Engine：列出 Unreal C++ 工作負載與 Visual Studio Tools for Unreal Engine 的安裝項目。
  • GitHub Docs：Getting started with GitHub Desktop：說明安裝、登入、加入或複製版本庫，以及查看變更的基本流程。
  • OpenAI：介紹 Codex 應用程式：介紹 Codex 桌面應用程式的多 Agent 協作、Skills 與自動化功能。

上課前確認

  • Unreal Engine 5.8 能開啟 ThirdPersonTemplate。
  • Visual Studio 2026 能開啟專案並完成編譯。
  • GitHub Desktop 能辨識教材版本庫與目前變更。
  • 四個關卡都能進入 PIE。
  • 重新開啟專案時會直接進入 Lvl_Combat。
  • 兩組實作的畫面與比較紀錄已備妥。
