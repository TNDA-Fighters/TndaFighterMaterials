課前實作練習

課前實作練習 1｜對調鍵盤 U／I，保留搖桿 X／Y

細步驟解答

  1. 停止 PIE，在 Content Browser 雙擊 /Game/Fighting/Input/IMC_Combat。展開 IA_Attack1、IA_Attack2 的 Mappings，找出目前為 U、I 的鍵盤列；確認兩筆搖桿列仍是 Gamepad_FaceButton_Left／Gamepad_FaceButton_Top。
  2. 只把 IA_Attack1 的 U 改為 I，把 IA_Attack2 的 I 改為 U；使用鍵位欄的選擇器或點選捕捉鍵位。保留原 Action、Modifiers、Triggers 與其他 15 筆映射，儲存 IMC。
  3. 開啟 stage1 並 Play，點一下遊戲視窗取得輸入。放開方向後分別短按 U、I，每次等待動作完整結束。U 預期是 AM_Attack_02 與特寫，I 是 AM_Attack_01。搖桿 X／Y 分別保持基本／第二攻擊；沒有搖桿裝置時，明列此項未展示，不以鍵盤測試代替。
  4. 請學生指出 IMC、Action 與 C++ 繫結的三層責任。表格只接收 X／Y，不知道實體 U／I；同 Action 的搖桿列未改，所以保留對應。
  5. 停止 PIE，把第一攻擊鍵位還原 U、第二攻擊還原 I，儲存並重開 PIE 確認。下一題以還原後的設定開始。

課前實作練習 2｜讓前方攻擊改播第三份動畫

細步驟解答

  1. 確認 U／I 已還原。停止 PIE，以 UTF-8 編輯器開啟專案 _DataTable/CommandTable.csv；只將 ID 2 的 AM_Attack_01 改成 AM_Attack_03，保留 "6,X" 的 CSV 引號與七個欄位，儲存來源。
  2. 在 Content Browser 右鍵 /Game/DataTable/DT_Command，選 Reimport，開表確認 Row 2 的 Montage 已改成短名 AM_Attack_03；Row 1 仍為 AM_Attack_01，兩列 Priority 仍為 0。儲存表格。
  3. 在 stage1 Play，先放開方向短按 U，再依雙方站位按住朝向對手的 A 或 D 並短按 U。每次等攻擊完整結束；後者預期改播第三份動畫。放開方向後再按 U，預期回到第一份。
  4. 同 Priority 時，符合的方向列排在單鍵列前。不要只以兩個相同動畫辨認選中列；本題刻意換成不同動畫，讓差異可見。無方向或尚在攻擊鎖定時，分別可能選基本招或拒絕新招。
  5. 停止 PIE，把 CSV Row 2 Montage 還原 AM_Attack_01，再 Reimport、儲存表格並核對。不能只在表格手動改回而留下錯誤 CSV。

課堂示範

課堂示範 1｜CSV 如何成為遊戲讀得到的招式資料？

示範重點

以 CSV、DataTable、FTndaCommandRow 和 FTndaCommand 分清來源、匯入格式、整理結果與當次副本。ID 是列名，Command 是 TableId；兩者都不等於 X／Y。有效 Reimport 使下一次查詢重建，當次播放不改倍率；任何驗證錯誤使整表不可用，不是略過壞列。GameInstanceSubsystem 是同次遊戲共用的入口；Unity 對照可類比共用資料管理責任，但不等於 ScriptableObject 或 MonoBehaviour 的生命週期。

課堂示範 2｜同一個 X 怎麼選招，選中資料又如何決定鏡頭？

示範重點

按攻擊當下取方向，候選先看 Priority，再看有無方向條件，最後看數值 ID；方向列沒有天然的絕對優先權。Priority 不會打斷正在播放的攻擊。CameraShot 隨選中資料儲存，None 與 UpperBodyCloseUp 只選已有構圖，不增加鏡頭型別。

課堂實作

課堂實作 1｜只把基本攻擊調成半速

題目

只把 CSV ID 1 的 PlayRate 從 1.0 改為 0.5，匯入到既有 DT_Command；保留 ID 2 與 Montage 素材設定。分享桌面展示兩列倍率、不按方向的半速基本攻擊，以及按住 6 後仍以原速播放的前方攻擊。兩招結束後都應恢復移動。說明：相同動畫為什麼只有一招變慢？

參考答案

  1. 停止 PIE，先核對 ID 1、2 都使用 AM_Attack_01、PlayRate 都是 1.0。只將 _DataTable/CommandTable.csv Row 1 的 PlayRate 改為 0.5，儲存。
  2. 右鍵 DT_Command Reimport，核對 Row 1=0.5、Row 2=1.0 並儲存。不要開 Montage 片段修改其 Play Rate。
  3. Play 後以 U、6+U 比較，等各自完整淡出後再試移動。兩筆招式使用不同資料副本，Row 1 的播放呼叫收到 0.5，Row 2 收到 1.0。
  4. 停止 PIE，將來源 Row 1 恢復 1.0，Reimport、儲存並核對。

課堂實作 2｜保留 Y 招動畫，取消它的特寫鏡頭

題目

只在 DataTable Editor 把 ID 3 的 CameraShot 改為 None，保留 CSV 原值與第二攻擊動畫。分享桌面展示按 I 仍播放第二攻擊、鏡頭維持正常構圖；接著由原 CSV Reimport，展示特寫恢復。說明：為什麼 Reimport 會覆蓋剛剛在表格改的值？

參考答案

  1. 停止 PIE，先核對 CSV Row 3 為 UpperBodyCloseUp、表格起始值相同。雙擊 DT_Command，選 Row 3，在 Row Editor 的 CameraShot 下拉選 None，保留 Montage=AM_Attack_02、PlayRate=1.0；儲存。
  2. Play，放開方向按 I，預期第二攻擊照常播放、沒有特殊構圖；等結束後停止 PIE。
  3. 不先手動改回表格，也不回寫 CSV。直接在 Content Browser 右鍵該表 Reimport，核對 Row 3 又是 UpperBodyCloseUp，儲存，重開 PIE 按 I 展示恢復。
  4. enum 中文顯示名稱是編輯器標籤；CSV 使用原生 enum token。Reimport 重新由正式來源建立列，因此會覆蓋表格中的暫時修改。
