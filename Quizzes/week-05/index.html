WEEK 05 · 實作測驗

雙人鍵盤對打

測驗題目與繳交內容

實作題：本地雙人鍵盤對打

題目

從 week-05 專案開始，把原本一人操作的格鬥遊戲改成兩人共用一把鍵盤。兩人要能同時移動、繞行、推擠與出拳，並沿用現有的角色、場地與相機。

操作方式

操作 1P 2P
移動 WASD ↑、↓、←、→
出拳 U Num7（數字鍵盤的 7）

實作提示

  • 先理解預設的輸入分配。 鍵盤輸入預設交給第 1 組 PlayerController（索引 0），後續本機玩家則使用搖桿。新增第 2 個 PlayerController 不會自動把同一把鍵盤的部分按鍵分給 2P。因此，本題沿用預設輸入配置時，兩組按鍵都要由 PlayerCharacter 接收，再把 2P 的指令轉發給 CpuCharacter。
  • 先把按鍵分開。 目前方向鍵也會控制 1P，要把它改成只控制 2P。可以新增 IA_P2Move、IA_P2Attack，在 IMC_Combat 設定方向鍵與 Num7。
  • 利用場上現有的 CPU 當 2P。 在 PlayerCharacter 綁定第二組 Input Action，透過現有的 GetOpponent() 取得 CpuCharacter，再轉發移動、停止移動與出拳指令，不必再生一個角色。
  • 兩人都依畫面方向移動。 參考 1P 現有的移動寫法，讓 2P 也使用同一個相機方向。不要用角色自己的朝向，否則換邊後按鍵方向可能跟著反轉。
  • 沿用原本的移動與出拳功能。 CPU 沒有玩家控制器，要確認它仍能移動。出拳可以呼叫現有 TryExecuteCommand("X")，讓既有程式處理動畫與出拳時暫停移動。

驗收

  1. WASD 與 ↑↓←→ 同時操作，確認移動、繞行、推擠功能有如預期。
  2. 同時按 U／Num7，兩方都同時出拳。
  3. 長按 → 時再按下 Num7，2P 會出完拳後繼續移動。

繳交內容

  1. Git commit 異動歷程：從 week-05 專案內容開始，隨實作進度分次 commit，保留可理解的 commit log。訊息要看得出這次改了什麼，例如「新增 2P 方向鍵與出拳按鍵」、「讓 CPU 接收第二組鍵盤操作」；不要全部做完後只留一筆「完成」或使用「update」等無法辨識內容的訊息。程式碼與 Input／Blueprint 資產都要納入版本控制。
  2. ASSESSMENT.md：放在專案根目錄，依下列格式說明做法與驗收結果。內容以自己的話簡短描述；未完成或未測試的項目要明寫。
