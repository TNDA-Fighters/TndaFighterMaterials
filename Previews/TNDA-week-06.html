課前預習

課前預習 1｜按鍵、輸入動作與 X／Y 語意

先認識三層輸入

U／I 是實體鍵盤按鍵；Input Action 是「要做什麼」的輸入動作；X／Y 是選招程式收到的攻擊語意。X／Y 名稱沿用 Xbox 按鈕，不能直接當成鍵盤 X／Y。/Game/Fighting/Input/IMC_Combat 把 U 接到 Boolean 型別的 Actions/IA_Attack1、I 接到 Actions/IA_Attack2，搖桿 X／Y 也各接到同一個 Action。

6 表示靠近對手，4 表示遠離對手，與角色站在螢幕哪一邊有關。1P 在對手左邊時，D 通常是 6；換邊後 A 才是 6。8／2 是本教材 W／S 的方向語意，不代表跳躍／蹲下。6,X 表示按住 6 時按下 X，逗號不表示輸入歷史。

從事件繫結追到放招入口

閱讀 Source/TndaFighter/Fighting/FightingPlayerCharacter.cpp 的 AFightingPlayerCharacter::SetupPlayerInputComponent()、Attack()、SampleAttackDirections() 與 TryExecuteCommand()。

  1. SetupPlayerInputComponent() 把 AttackAction 的 Started 綁到 Attack(..., FName("X"))，把 AttackAction2 綁到同一函式的 Y 引數。此版本按下時嘗試一次，長按不連發。
  2. 引擎送出繫結的事件時，Attack() 取得 X／Y，再呼叫 SampleAttackDirections()。這一步直接讀 Enhanced Player Input 的 MoveAction 當下 Axis2D 值，不取前一個移動事件留下的方向。
  3. SampleAttackDirections() 以攝影機水平角度與雙方位置判定 4／6，並從移動 Y 軸產生 8／2；輸出是一組方向整數。來源無效時輸出空集合，仍可比對單鍵招。
  4. Attack() 把攻擊語意與方向集合交給玩家 TryExecuteCommand()；玩家有有效控制者時再呼叫共同父類入口，接續預習 2。

C++ 呼叫已確認；從實體鍵到 Action 事件由 Enhanced Input 執行，串接依據是當次 IMC 回讀與 BindAction 兩側配置，事件實際觸發仍須在 PIE 操作。

修改時先找責任

/Game/Fighting/Blueprints/BP_FightingPlayerCharacter 的 AttackAction、AttackAction2、MoveAction 各參照上述三個 Action。要換實體鍵位就改 IMC；要改 X／Y 對應的動畫就改招式表。兩筆搖桿映射是獨立接線，交換鍵盤 U／I 不必交換搖桿。

課前預習 2｜從放招入口追到資料表的動畫設定

先分清來源、資產與副本

CSV 是編輯來源；DataTable 是匯入後的資產；Row 是一列設定。Row Name 是列的識別，這裡由 ID 欄匯入；Command 則是表格登記的 TableId。Keys 才是招式的輸入條件，X 不是 Row Name。

Source/TndaFighter/DataTable/TndaCommandData.h 的 FTndaCommandRow : FTableRowBase 宣告 Title、Keys、Montage、PlayRate、Priority、CameraShot 六個欄位。加上被匯入器消耗的 ID，CSV 共七欄。Reader 把字串解析成可用的 FTndaCommand，其中 Montage 是資產參照；複製招式資料不等於複製動畫資產。

ID／Row Name Keys Montage PlayRate Priority CameraShot
1 X AM_Attack_01 1.0 0 None
2 6,X AM_Attack_01 1.0 0 None
3 Y AM_Attack_02 1.0 0 UpperBodyCloseUp

從條件比對追到播放

  1. 從 Source/TndaFighter/Fighting/FightingCharacter.cpp 的 AFightingCharacter::TryExecuteCommand() 開始。已有攻擊、沒有有效對手或不在一般地面狀態時，拒絕新的嘗試，不排隊。
  2. 入口呼叫 Source/TndaFighter/DataTable/TndaCommandReader.cpp 的 UTndaCommandReader::TrySelectCommand()。Reader 經 TndaDataTableSubsystem.cpp 的 FindPreparedTable("Command") 取得整理好的招式。
  3. Prepare() 將招式依 Priority 大到小、同值時有方向者優先、最後數值 ID 小到大排序。TrySelectCommand() 從前往後找第一筆攻擊語意相同、方向條件成立的資料，複製到 Selected。單鍵 X 沒有額外方向條件，按 6 時也可成為候選。
  4. 回到共同角色，確認 AnimInstance 與播放引數有效後呼叫 Montage_Play(Selected.Montage, Selected.PlayRate, ...)。成功才把資料移入 CurrentAttack，儲存當次招式、鎖住新攻擊。

以上為已確認原始碼路徑；表格三列與三份動畫內容也由本次 Editor 回讀。

改值何時生效

只儲存 CSV 不會自動更新 DT_Command，必須 Reimport。有效表格變動使 Reader 快取失效，下一次查詢才重建；正在播放的 CurrentAttack 保留原資料。PlayRate 是當次播放倍率，0.5 會降低播放速度；它與 Montage 片段自己的 Play Rate 是不同設定層。CameraShot 也是同一筆招式資料的一部分，Y 列目前要求上半身特寫。

課前實作練習 2｜讓前方攻擊改播第三份動畫

從原始鍵位設定開始，只把 _DataTable/CommandTable.csv 的 ID 2 Montage 改為既有 AM_Attack_03，並讓 DT_Command 採用這份更新。保留其他列、欄位與動畫資產。
